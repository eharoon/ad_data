# ad_data

Data and analyses for the Alzheimer's disease (AD) line of work in the Emory Behavioral Immunology Program.

This repository is kept separate from `research-positions`, the cross-project wiki of standing research positions. Material here is project-specific: datasets, analysis scripts, and outputs. When this work produces a durable position, the position goes into `research-positions`, which then cites this repository.
